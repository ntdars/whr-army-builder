# Warhammer Renaissance — Army List Builder

A React + Vite app. Rosters save to your browser's `localStorage`,
so they'll be there next time you open the site on the same
browser/device, but won't follow you across devices.

## Local development

```
npm install
npm run dev
```

## Deploying (one-time setup)

1. Create a free GitHub account at github.com if you don't have one.
2. Create a new repository (e.g. `whr-army-builder`) — public or
   private, either works.
3. Push this folder to that repository.
4. Create a free Vercel account at vercel.com, signing in with GitHub.
5. In Vercel, click "Add New Project," pick your repository, and
   click Deploy. Vercel auto-detects Vite — no config needed.
6. You'll get a live URL like `whr-army-builder.vercel.app`.

## Updating later

Push new commits to the same GitHub repo (`git add`, `git commit`,
`git push`) and Vercel redeploys automatically within a minute or
two. No need to touch Vercel again after the first setup.
